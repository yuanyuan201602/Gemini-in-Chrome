# 情境化可视化解题（原型）

把一道物理题变成真实场景，用 3D 动画一步步演示解题过程，同时同步显示图像（v–t、x–t、投影图）、方程推导，并配有中文语音讲解和字幕，适合课堂大屏演示。

## 两道示例题

| 题目 | 场景 | 同步图像 | 讲解要点 |
| --- | --- | --- | --- |
| 追及问题：警车追货车（含限速） | 城市道路、货车、警车（警灯闪烁）、路边距离牌 | v–t 图（面积差 = 距离）、x–t 图（交点 = 追上） | 共速时距离最大；直接列方程得 9.66 s 是错的（超速），必须分段 |
| 3D 电磁场：磁聚焦螺旋线 | 实验台、真空玻璃管、螺线管、质子源、荧光屏 | 沿 B 方向的 xy 投影圆、z–t 图 | 速度分解；垂直分量做圆周、平行分量做匀速直线；螺距；一束质子汇聚于一点 |

## 使用

- **离线直接打开**：`dist/index.html` 是打包好的单个文件，双击用 Chrome / Edge 打开即可，无需联网。
- **开发**：

```bash
npm install
npm run dev     # 本地开发，http://localhost:5173
npm run build   # 重新生成 dist/index.html
```

操作：`空格` 播放/暂停，`←` `→` 上一步/下一步，`R` 重播本步；3D 画面可拖动旋转、滚轮缩放。勾选“自动连播”可一路讲完。
语音使用浏览器自带的中文语音（Windows / macOS 通常自带）；没有中文语音时只显示字幕。

## 结构

```
src/core/      播放器（步骤、时间轴、语音、方程）、3D 舞台、2D 画图
src/models/    3D 模型：车辆、街道、实验装置
src/problems/  每道题一个文件：物理量、解题步骤（字幕 + 公式 + 镜头）、场景和图像
```

新增一道题：在 `src/problems/` 里仿照现有文件写 `steps`（每步的讲解词、公式、动画时间段）和 `mount()`（搭场景、每帧更新、画图），再在 `src/main.js` 注册。
